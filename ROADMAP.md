# Roadmap

Chronicle v0.1.0 is a single-date prototype. The following work is planned for future releases.

- **Dynamic date selection.** Add a date argument and support separate editions.
- **Historical event retrieval.** Retrieve date-matched reporting and retain source links and publication dates.
- **SQLite integration.** Store editions, stories, and source metadata locally.
- **Streamlit interface.** Select a date, preview the infographic, and download the PNG.
- **Automated testing.** Cover input validation, date handling, and repeatable rendering, then run the suite in CI.
- **Deployment.** Package and deploy the Streamlit application with documented runtime and configuration requirements.
